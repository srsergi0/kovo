# 01. Getting Started with Kovo

Welcome to **Kovo**! This guide will walk you through setting up your environment, understanding the project architecture, building your first TSX page, and running it in the live Xiaomi Vela smartwatch emulator.

---

## 📋 System Requirements

To build and run Kovo applications, ensure your machine has:

- **Node.js**: `v18.x` or `v20.x` (or `v24.x`).
- **Bun**: `v1.x` (recommended fast JavaScript runtime).
- **AIoT Toolkit / Xiaomi Vela CLI**: Provided via `@aiot-toolkit/aiotpack` / `aiot`.
- **Operating System**: Windows (PowerShell/CMD), macOS, or Linux.

## 📁 Repository Directory Structure

```text
kovo/
├── docs/                      # Comprehensive English Documentation
├── scripts/
│   ├── babel-plugin-vela-ux.js # Core AST Babel Transformer Engine
│   ├── build-jsx.js           # Build Orchestrator (TSX -> .ux)
│   ├── copy-static.js         # Auto-router & manifest sync tool
│   ├── dev-emulator.js        # Zero-Config Emulator Launcher
│   ├── babel-plugin-vela-ux.test.js # Compiler Unit Tests
│   └── hpd.test.js            # Production Integration Test Suite
├── src-tsx/                   # YOUR TSX SOURCE CODE
│   ├── app.tsx                # Application Lifecycle Entrypoint
│   ├── manifest.json          # App Metadata & Permissions Configuration
│   ├── components/            # Reusable Cross-File TSX Components
│   │   └── StatCard/
│   └── pages/                 # Smartwatch Pages / Views
│       ├── index/             # Main Smartwatch Dashboard
│       ├── demo/              # Counter & State Demo Page
│       ├── network/           # HTTP Network Fetch Demo Page
│       └── settings/          # Device Settings Page
├── src/                       # GENERATED QUICKAPP (.ux) OUTPUT
│   ├── manifest.json
│   └── pages/
├── build/                     # Compiled JS Bundle Output
├── dist/                      # Production Signed .rpk Binary Output
└── package.json
```

> [!IMPORTANT]
> **Never write application code in `src/`**. Always write your code in `src-tsx/`. The `src/` directory is automatically wiped and regenerated by `bun run build`.

## 🛠️ Step 1: Installation & Setup

Clone the repository and install all dependencies using `bun`:

```bash
# 1. Clone the repository
git clone https://github.com/your-org/kovo.git
cd kovo

# 2. Install dependencies
bun install
```

---

## 🚀 Step 2: Running the Live Smartwatch Emulator

Kovo includes a zero-configuration emulator launcher (`scripts/dev-emulator.js`). It automatically handles:

1. Auto-patching `config.ini` image directories if paths are missing.
2. Auto-creating a 466x466 Redmi Watch / Xiaomi Watch S4 Virtual Device (`Vela_Virtual_Device`) if none exists.
3. Transpiling TSX to `.ux`, building `.rpk`, pushing to emulator, and starting the live hot-watcher.

Run the emulator script:

```bash
bun run dev:emulator
```

The 466x466 OLED smartwatch emulator window will appear instantly on your screen, rendering the dashboard!

## ✍️ Step 3: Writing Your First TSX Page

Create a new file `src-tsx/pages/hello/hello.tsx`:

```tsx
import { useState } from 'kovo-ux';
import router from '@system.router';
import vibrator from '@system.vibrator';

export const style = `
  .page {
    width: 466px;
    height: 466px;
    background-color: #06080c;
    flex-direction: column;
    align-items: center;
    justify-content: center;
  }
  .title {
    font-size: 20px;
    font-weight: bold;
    color: #38bdf8;
    margin-bottom: 16px;
  }
  .counter-btn {
    width: 200px;
    height: 50px;
    background-color: #052e16;
    border-color: #16a34a;
    border-width: 1px;
    color: #4ade80;
    border-radius: 25px;
    font-size: 16px;
    font-weight: bold;
  }
`;

export default function HelloPage() {
  const [count, setCount] = useState(0);

  function increment() {
    try { vibrator.vibrate({ mode: 'short' }); } catch (e) {}
    setCount(count + 1);
  }

  return (
    <div className="page">
      <text className="title">Hello Vela: {count}</text>
      <input className="counter-btn" type="button" value="TAP ME" onClick={increment} />
    </div>
  );
}
```

### What Happens Behind the Scenes?

1. `scripts/copy-static.js` detects `hello.tsx` and automatically registers `"pages/hello": { "component": "hello" }` inside `src/manifest.json`.
2. `scripts/babel-plugin-vela-ux.js` converts `HelloPage` into `src/pages/hello/hello.ux`.
3. `increment()` is bound to `export default { protected: { count: 0 }, increment() { this.count = this.count + 1; } }`.
4. `bun run dev:emulator` hot-reloads the app on the watch!
