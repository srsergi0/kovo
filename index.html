React TSX → Xiaomi Vela QuickApp

Write React. Ship native.

Zero runtime, made native

Kovo compiles function components and hooks into native .ux files for Vela smartwatches at build time. No React ships to the watch, only its own ViewModel.

See how

01 — Write

The React you already know.

State, derived values, effects, events. Plain function components with hooks, typed with TypeScript.

  • useState, useEffect, useMemo, useRef
  • Custom hooks, inlined at compile time
  • @system.* APIs fully typed

02 — Compile

Every hook becomes native Vela.

babel · build time

03 — Map

React semantics, Vela runtime.

Scope-aware Babel rewrites — never regex. Setters become assignments, arrays update in place, refs become $element().

setList([...list, a])

→ this.list.push(a)

in-place, per the memory guide

useEffect(fn, [a])

→ onInit + $watch('a')

cleanups run before re-runs and on destroy

useRef() + ref=

→ this.$element('r')

focus(), scrollTo(), getBoundingClientRect()

onSelect(a, b)

→ this.$emit('select')

parent receives (a, b)

<Badge label=… />

→ inlined

stateless components cost nothing

useFetch(url)

→ inlined hook

call it twice, state stays separate

04 — System APIs

Fetch, lists, conditionals.

.map() becomes for with a tid, ternaries become if/else, and network data is trimmed before it is stored.

05 — Frugal by default

Vela closes apps that use too much memory.
Kovo writes code that doesn't.

06 — Iterate fast

A simulator in your browser.

bun run sim runs the official toolkit's build output with a DOM renderer and live reload. Round, rect and band profiles, real fetch, phone ↔ watch messages.

Then bun run dev:emulator for the real Vela emulator.

Get started

Your first watch app
in one command.

$ npm create kovo-ux@latest my-watch-app
$ cd my-watch-app && bun install
$ bun run dev:emulator
✓ build success · installed on emulator
